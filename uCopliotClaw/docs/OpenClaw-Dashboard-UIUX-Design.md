# OpenClaw Dashboard UI/UX 设计方案

企业级管理后台风格，功能丰富、信息密度高，参考 Ant Design Pro 设计规范。

---

## 一、设计风格定位

### 1.1 视觉风格

| 特征 | 说明 |
|------|------|
| **主题** | 浅色主题为主，支持深色切换 |
| **布局** | 左侧固定导航 + 顶部工具栏 + 内容区 |
| **色彩** | 主色蓝 (#1677ff)，辅色灰，状态色丰富 |
| **字体** | 系统字体栈，中文优先苹方/思源黑体 |
| **间距** | 8px 基础单位，24px 卡片内边距 |
| **圆角** | 6px 控件圆角，8px 卡片圆角 |

### 1.2 设计原则

1. **信息层级清晰** - 重要信息突出，次要信息收敛
2. **操作高效** - 减少点击次数，支持快捷键
3. **状态可见** - 所有操作有明确反馈
4. **容错设计** - 危险操作需二次确认
5. **响应式** - 支持宽屏 (1920px+) 和标准屏 (1366px)

- 用量图表支持切换时间范围

## 四、组件规范

### 4.1 基础组件

| 组件 | 说明 | 样式规范 |
|------|------|---------|
| Button | 主按钮/次按钮/文字按钮/危险按钮 | 高度 32px，内边距 12px |
| Input | 文本输入框 | 高度 32px，边框 #d9d9d9 |
| Select | 下拉选择器 | 高度 32px，支持搜索 |
| Switch | 开关 | 宽度 44px，高度 22px |
| Table | 数据表格 | 行高 54px，斑马纹 |
| Card | 卡片容器 | 圆角 8px，阴影 0 1px 2px rgba(0,0,0,0.03) |
| Modal | 模态框 | 宽度 520px，居中显示 |
| Drawer | 抽屉 | 宽度 480px，右侧滑出 |
| Tooltip | 提示 | 深色背景，白色文字 |
| Badge | 徽标 | 圆点/数字，状态色 |

### 4.2 状态色

| 状态 | 颜色 | 用途 |
|------|------|------|
| 成功 | #52c41a (绿) | 在线、成功、正常 |
| 警告 | #faad14 (黄) | 警告、待处理 |
| 错误 | #ff4d4f (红) | 离线、错误、失败 |
| 信息 | #1677ff (蓝) | 信息、进行中 |
| 默认 | #d9d9d9 (灰) | 禁用、未知 |

### 4.3 图标规范

使用 Lucide React 图标库，统一尺寸:
- 导航图标: 20px
- 操作图标: 16px
- 状态图标: 8px (圆点)

## 五、交互规范

### 5.1 表单交互

| 场景 | 交互 |
|------|------|
| 必填项未填 | 提交时标红，显示"此项为必填" |
| 格式错误 | 实时验证，失焦时显示错误 |
| 保存成功 | Toast 提示 "保存成功"，2s 后消失 |
| 保存失败 | Toast 提示错误原因，表单保持编辑状态 |
| 取消编辑 | 弹窗确认 "确定取消？未保存的更改将丢失" |

### 5.2 列表交互

| 场景 | 交互 |
|------|------|
| 删除单项 | 弹窗确认 "确定删除？此操作不可恢复" |
| 批量删除 | 弹窗确认 "确定删除选中的 N 项？" |
| 刷新列表 | 加载动画，保持当前筛选条件 |
| 空列表 | 显示空状态插图 + 引导文案 |

### 5.3 实时数据

| 场景 | 交互 |
|------|------|
| 数据更新 | 平滑过渡动画 (300ms) |
| 新日志条目 | 自动滚动到底部，高亮新条目 2s |
| 状态变化 | 颜色渐变 + 图标动画 |
| 断开连接 | 显示重连提示 + 重连按钮 |

### 5.4 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + S` | 保存当前编辑 |
| `Ctrl + F` | 聚焦搜索框 |
| `Esc` | 关闭抽屉/弹窗 |
| `?` | 显示快捷键帮助 |

## 六、响应式适配

### 6.1 断点定义

| 断点 | 宽度 | 布局调整 |
|------|------|---------|
| xl | ≥1920px | 侧边栏展开，内容区最宽 |
| lg | ≥1366px | 标准布局 |
| md | ≥1024px | 侧边栏可折叠 |
| sm | <1024px | 侧边栏收起为抽屉 |

### 6.2 适配策略

- 统计卡片: 4列 → 2列 → 1列
- 表格: 横向滚动，固定首列
- 抽屉: 全屏宽度
- 侧边栏: 收起为图标模式或抽屉模式
